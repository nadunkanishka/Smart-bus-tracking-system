## Folder map

```
backend/                 API server
  index.js               Starts the server and mounts the route files (order matters: public first, then admin guards)
  routes/                One file per resource: auth, passengers, drivers, buses, routes, monitoring, health
  middleware/            Rate limiter for sign-in, admin-only guards
  realtime.js            Socket.IO: driver fixes in, bus updates out
  lib/                   ETA engine, GPS validation, trip tracker, geometry, auth helpers, latest-fix store
  models/                Mongoose schemas
  scripts/               seed, replay (simulated buses), clear-sim-data, smoke (endpoint check)
  test/                  node --test unit tests

apps/passenger-app/      Expo app for passengers
apps/driver-app/         Expo app for drivers
  App.js                 Root: holds navigation state and switches between screens
  src/screens/           One file per screen, each with its .styles.js
  src/components/        Pieces used by the screens
  src/hooks/             (passenger) session, routes, live buses, toast
  src/services/          (driver) telemetry.js: GPS, offline queue, socket
  src/constants.js       App constants
  src/utils.js           Pure helper functions
  src/styles/            app.js (root styles), common.js (styles used by more than one screen)
  src/shared/            GENERATED by shared/sync.js. Do not edit here.
  assets/                App icons; assets/buses/ is generated

apps/admin-dashboard/    React web app for the admin
  src/App.js             Root: sign-in state, shell, page switch
  src/pages/             One file per page
  src/components/        Sidebar, Header, dialogs, forms, small UI pieces
  src/hooks/             useAdminData (loading), useEntityModal (add, edit, delete)
  src/api.js             fetch wrapper that adds the admin token
  src/styles/            admin-theme.css, index.css
  src/design/            GENERATED by shared/sync.js. Do not edit here.

shared/                  Source of the design system; sync.js copies it into the three apps
docs/                    Architecture, API, database, deployment, evaluation, this file
loadtest/                Artillery load test (see EVALUATION.md)
```

## The one rule about shared code

Metro (Expo) and Create React App both refuse to import files from outside their own app folder. So shared code lives in `shared/` and is **copied** into each app:

```bash
node shared/sync.js        # or: npm run sync
```

- Mobile apps receive the copies in `src/shared/` and `assets/buses/`.
- The admin receives them in `src/design/`.
- Never edit a copy. Edit the file in `shared/` and run the sync. CI fails if a copy differs from its source.

## Naming

| Thing | Rule | Example |
|---|---|---|
| Folders | kebab-case | `driver-app`, `admin-dashboard` |
| React components, screens, pages | PascalCase file, same name as the component | `StopPicker.js` |
| Hooks | `useX`, camelCase file | `useRoutes.js` |
| Other modules | camelCase | `telemetry.js`, `tripTracker.js` |
| Styles for one screen | `<Name>.styles.js` beside it | `RoutesScreen.styles.js` |
| Constants | UPPER_SNAKE | `STALE_MS` |
| Docs | UPPERCASE | `STRUCTURE.md` |
| Bus images | `<vehicle>-<livery>-<state>.webp` | `bus-coral-running.webp` |

One component per file. Imports are relative and never deeper than `../`.

Two files are deliberately large: `shared/native/ui.js` (the mobile UI kit: many small components that are synced as one unit) and `apps/admin-dashboard/src/styles/admin-theme.css` (later sections override earlier ones, so the order must stay intact).

## Adding things

**A REST endpoint.** Add the handler to the matching file in `backend/routes/`, with the full path (`/api/...`). A new resource gets a new file, mounted in `backend/index.js`: above the admin guards if it is public, below if it is admin-only. Add a call to `backend/scripts/smoke.js`.

**A mobile screen.** Create `src/screens/NameScreen.js` and `NameScreen.styles.js`, then render it from the tab switch in `App.js`. If two screens need the same style, move it to `src/styles/common.js`.

**An admin page.** Create `src/pages/NamePage.js`, add it to the page switch in `src/App.js` and to the list in `src/components/Sidebar.js`.

**A shared component or token.** Edit `shared/`, run `node shared/sync.js`, commit both the source and the copies.

**A bus illustration.** Add it in `shared/buses/`, then run `node shared/buses/export.mjs` and `node shared/sync.js`.

## Environment variables

Each part reads its own file. Copy the `.env.example` beside it.

| Part | File | Variable | Needed? | Purpose |
|---|---|---|---|---|
| Backend | `backend/.env` | `JWT_SECRET` | Yes | Signs login tokens |
| | | `ADMIN_PASSWORD` | Yes | Password of the first admin account |
| | | `ADMIN_USERNAME` | No (default `admin`) | Name of the first admin account |
| | | `MONGODB_URI` | No (local default) | MongoDB connection |
| | | `PORT` | No (default 5000) | API port |
| | | `REDIS_URL` | No | Latest-fix cache; empty uses memory |
| | | `CORS_ORIGIN` | Production only | Allowed web origins, comma-separated |
| | | `OSRM_URL` | No | Routing server used by `npm run seed` |
| Admin | `apps/admin-dashboard/.env.local` | `REACT_APP_API_URL` | No (default `http://localhost:5000`) | Backend address |
| | | `REACT_APP_OSRM_URL` | No | Routing server for the route editor |
| Driver, passenger | `apps/*/.env` | `EXPO_PUBLIC_API_URL` | Real phones only | Backend address on your network |
| | | `EXPO_PUBLIC_GOOGLE_MAPS_API_KEY` | Native builds only | Google Maps key |
| Driver | `apps/driver-app/.env` | `EXPO_PUBLIC_DISPATCH_PHONE` | No | Number shown for dispatch |

After changing an `EXPO_PUBLIC_` value, restart Expo with `-c` so the cache is cleared.

## Branches and commits

- Never commit to `dev` or `main` directly. Work on a branch and open a pull request into `dev`.
- Branch names: `feat/<topic>`, `fix/<topic>`, `chore/<topic>`, `docs/<topic>`, or one of the long-lived area branches (`ui`, `database`, `docs`).
- Commit messages: `type(scope): what changed`, for example `fix(eta): ignore fixes older than the last stop`.
